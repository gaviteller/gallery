# Gallery Color Palettes

## Current (Dark Purple — v1, shipped)

```css
:root {
  --bg:      #0F0D14;   /* page background */
  --surface: #1C1825;   /* cards, panels */
  --border:  #2A2438;   /* dividers, borders */
  --text:    #F0EBF8;   /* primary text */
  --muted:   #6B5F88;   /* secondary text, icons */
  --nav:     #16131E;   /* sticky nav bar */
  --grad:    linear-gradient(90deg, #FF3CAC, #784BA0, #2B86C5); /* brand gradient */
}
```

**Vibe:** Deep purple-dark space. Pink→violet→cyan gradient for accent. Cool, editorial, premium art platform feel.

---

## Candidates tested — all rejected, original wins

- **Crimson** (`#0C0808` bg, blood-red gradient) — too dark/harsh
- **Sage** (`#0D0E0A` bg, rose→brown→olive gradient) — earthy but off-brand
- **Homely** (`#0F0B08` bg, amber→sienna gradient) — warm but not better than purple

Original dark purple palette is the keeper.
